# AI Agent - 多工具智能助手

一个基于大模型（DeepSeek）和工具调用的智能代理系统，支持联网搜索、时间查询、数学计算、文件读写等功能。

## ✨ 功能特性

- 🔍 **联网搜索**：通过 SerpAPI 获取实时信息
- 🕐 **时间查询**：获取当前日期和时间
- 🧮 **数学计算**：支持复杂表达式运算
- 📝 **保存笔记**：将内容保存到本地文件
- 📖 **读取笔记**：查看之前保存的内容
- 💬 **多轮对话**：保持上下文记忆

## 🚀 快速开始

### 环境要求

- Python 3.10+
- DeepSeek API Key
- SerpAPI Key
